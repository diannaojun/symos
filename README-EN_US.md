# Symbol Operating System(Symbol OS)

## Breif Introduction

A simple `IA-32e` operating system, developed by the Symbol development team.

## Installation

Compile by yourself or download the precompiled ISO image from the Release.

## Compile

You need these programs (commands) to compile:
- NASM
- CC (like GCC)
- LD
- MAKE
- DD
- RM
- MKDIR

Note: If you encounter errors when compiling, please solve them yourself.

## Runtime Error

Please refer to [the error document](./doc/error_EN_US.md).
